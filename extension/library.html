Publishing instructions ↗

Same game view, different screens

New recordings use a 1440 × 757 game view, fitted into the browser. Recorded view size is restored during replay. This standardizes the game area, not the physical display.

Match the in-game zoom, camera direction, starting position, mission progress, and required items. Visual targets can still change or be ambiguous; the recorder pauses when it cannot find one.

Recording captures typed game text and small grayscale image patches. Do not enter private messages while recording. Password fields are excluded. No AI service, login credentials, or GitHub token is required.

Review recording

Public exports include typed text, space URLs, mission text, and small visual targets. Remove any private content before sharing. Deleting a text step does not delete its Enter key: review the adjacent steps too.
